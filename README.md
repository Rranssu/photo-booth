# 📸 Photo Booth

A simple desktop photo booth app inspired by Apple's **Photo Booth**, built with **Electron + React + Vite**.

## ✨ Features

* 📷 Webcam photo capture
* 🎨 Photo effects
* ⏱️ Countdown timer
* 🖼️ Photo preview
* 💾 Save photos locally
* 🪄 Simple, Apple-inspired UI

## 🛠️ Built With

* Electron
* React
* Vite
* JavaScript
* WebRTC

## 🚀 Run Locally

```bash
git clone https://github.com/Rranssu/photo-booth
cd photo-booth
npm install
npm run dev
```
